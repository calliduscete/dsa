# DSA in Java

A beginner-friendly collection of data structures and algorithms implemented in Java, with clear comments, complexity notes and examples you can run.

## Who is this for?

Students and beginners learning DSA, and anyone revising for exams or interviews.

## How to run the code

1. Install the JDK (version 17 or later).
2. Clone the repo:
   `git clone https://github.com/your-username/your-repo.git`
3. Go into a topic folder, then compile and run a file:
   `javac Example.java`
   `java Example`

## How each file is organised

- A comment at the top explaining what it does
- Time and space complexity noted in comments
- A `main` method with example usage

## Suggested learning order

Follow the folders in numeric order. Learn one topic, then solve a few easy problems on it before moving on.
